# References · Module 04

## Data versioning

1. **DVC documentation: Get started.**
   [dvc.org/doc/start](https://dvc.org/doc/start)
   The tutorial used in this lab, including `dvc init`, `add`, `push`, and `pull`.

2. **DVC documentation: Data and model versioning.**
   [dvc.org/doc/use-cases/versioning-data-and-models](https://dvc.org/doc/use-cases/versioning-data-and-models)
   Why cache and remote are separate, and what the `.dvc` file records.

3. **DVC documentation: `dvc remote`.**
   [dvc.org/doc/command-reference/remote](https://dvc.org/doc/command-reference/remote)
   All remote types, including the local directory used here.

## Validation

4. **pandera documentation.**
   [pandera.readthedocs.io](https://pandera.readthedocs.io/)
   Declarative schemas, `lazy=True` behaviour, and coercion. Check the version-compatibility notes before installing into an existing environment.

5. **Great Expectations documentation.**
   [docs.greatexpectations.io](https://docs.greatexpectations.io/)
   The heavier alternative to pandera. Named here because it appears in job adverts; this course does not require it, and its setup cost is not justified for a one-month dataset.

6. **Pandas documentation: `to_numeric` and missing data.**
   [pandas.pydata.org/docs/reference/api/pandas.to_numeric.html](https://pandas.pydata.org/docs/reference/api/pandas.to_numeric.html)
   `errors="coerce"` is the basis of the type checks in this module.

## Leakage and evaluation

7. **Kaufman, S., Rosset, S., Perlich, C., Stitelman, O. (2012). *Leakage in Data Mining: Formulation, Detection, and Avoidance.* ACM TKDD 6(4).**
   [Publisher page](https://dl.acm.org/doi/10.1145/2382577.2382579) (DOI `10.1145/2382577.2382579`; the publisher blocks automated retrieval and may require institutional access)
   The systematic treatment: definitions, why leakage inflates results, and detection strategies. Read the taxonomy even if the formal notation is heavy.

8. **scikit-learn: Common pitfalls and recommended practices.**
   [scikit-learn.org/stable/common_pitfalls.html](https://scikit-learn.org/stable/common_pitfalls.html)
   Short, practical, and specific about preprocessing leakage and data splitting.

9. **Sculley, D. et al. (2015). *Hidden Technical Debt in Machine Learning Systems.***
   [Paper page](https://proceedings.neurips.cc/paper/2015/hash/86df7dcfd896fcaf2674f757a2463eba-Abstract.html)
   The "data dependencies" section is the organisational counterpart to this module's checks.

## Note on the dataset

The RaviRide dataset is synthetic and generated by the course's `scripts/generate_trips.py` with seed 42. There is no licence question: no personal data, no third-party content. The README you write in the lab is therefore short - but write it as if it were not, because the structure is what transfers to real data.
